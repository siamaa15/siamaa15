### Young-Hee Doll — Red Light, Green Light Game
🔗 https://github.com/DoubleA-ron/RedLight_GreenLight

A Python-based game inspired by the “Red Light, Green Light” challenge from the Korean Netflix TV series "Squid Game". This is a team-based project.

**Key Contributions:**
- Implemented timing logic for Red Light / Green Light state transitions
- Integrated audio signals for gameplay feedback via external speaker
- Ensured synchronization between system timing and player interaction
- Contributed to system design using UML diagrams (class + use-case)
- Worked within a hardware-software integrated environment (Raspberry Pi + peripherals)
**System Features:**
- Real-time human motion detection using YOLO-based computer vision 
- Video processing using OpenCV for continuous player tracking   
- LED indicators and audio cues for interactive gameplay  
**Tech Stack:**
Python, OpenCV, YOLO (Ultralytics), Pygame, GPIOZero, Raspberry Pi
